# Sistema de Gestión de Inventario

Un sistema de gestión de inventario para el registro y administración de productos o mercadería.

Tecnologías utilizadas
* Python 3.11.0
* Base de datos: SQLite3

Características
* Menú interactivo en consola.
* Agregar, Consulta, actualización de stock y eliminación de productos.
* Manejo de excepciones para evitar errores de entrada de datos.
* Conexión y persistencia de datos en base de datos local.
